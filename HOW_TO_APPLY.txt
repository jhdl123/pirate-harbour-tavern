HOW TO APPLY
1. Make sure your working tree is clean and committed.
2. Extract this zip over the PROJECT ROOT (the folder containing project.godot).
   Do not extract into docs/ — the paths inside the zip are already relative to
   the project root.
3. Open the project once in the Godot editor, or run:
       godot --headless --editor --quit
   so tests/darts_score_probe.gd resolves. A .uid file is included, so this is
   belt-and-braces rather than required.
4. Commit.

RUNNING THE PROBE
    godot --headless res://tests/darts_score_probe.tscn
Takes about 4 minutes. Prints eligibility / cooldown / condition-blocked counts
for darts, the winner tally, and the mean contribution breakdown for relax vs
darts. It does NOT touch debug/latest/, so it will not overwrite your committed
diagnostic runs.

NOTE ON RUN VARIANCE
Two runs of this probe at 235b7ac gave darts "would win" 52/528 and 93/419.
The direction is stable and the mean scores barely move (10.20 vs 10.28); the
absolute counts vary with spawn timing. Compare the mean contribution
breakdown and the eligible-vs-occupancy gap, not the raw win counts.
