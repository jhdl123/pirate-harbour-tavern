HOW TO APPLY
============

1. Close Godot.
2. Extract over your project root (this is a diff against commit cd5067d, not a
   full replacement of the earlier ZIPs).
3. Reopen. If StationStockPlan shows as an unknown class, Project > Reload
   Current Project once.

VERIFY
------
  godot --headless res://tests/service_coverage_probe.tscn   -> 30 passed, 0 failed
  godot --headless res://tests/drinks_system_probe.tscn      -> 53 passed, 0 failed
  godot --headless res://tests/storeroom_props_probe.tscn    -> 52 passed, 0 failed

WHAT TO LOOK FOR IN GODOT
-------------------------
  - Seven stations: Grog, Cider, SmallBeer (poured) + 4 bottle services.
  - No station should ever ask for a Grog Barrel unless it pours kill-devil.
    The stock alert on the Port Wine shelf should now read "Port Wine Crate".
  - drinks_station.tscn now ships with NO drink and NO refill item. Any NEW
    station you instance will warn on startup until you set served_drink.
    That is deliberate - it is what stops the grog default returning.
