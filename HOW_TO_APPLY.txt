HOW TO APPLY
============
1. Close Godot.
2. Extract over your project root (three files; debug/ untouched).
3. Reopen, F10 → Export Diagnostic Run.

WHAT SHOULD CHANGE IN THE NEXT RUN
----------------------------------
  stock_report.txt   every display should read PASS, with a "Stock item:" line
                     naming grog_barrel / small_beer_cask / port_wine_crate etc.
  RUN_SUMMARY.md     Days: 1 rather than 0
                     tasks_created / completed / cancelled with real numbers
                     rather than three zeroes

TIP
---
Set "Test purpose" and "Developer notes" on Managers/DiagnosticRunExporter in
the inspector before exporting — your first run has them as "(not set)".

VERIFY
------
  godot --headless res://tests/diagnostic_export_probe.tscn   -> 59 / 0
