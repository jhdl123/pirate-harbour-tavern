Pirate Harbour Tavern - Customer Identity & Behaviour Foundation
Plus navigation diagnostic probes.

Baseline: commit dded922 ("commit check"). If your working copy has moved
on since then, check CHANGED_FILES.txt against your own changes before
extracting - the 19 MODIFIED files are full replacements, not patches.


HOW TO APPLY
------------
1. Back up your project folder (or commit what you have first).

2. Extract this zip OVER your project root, keeping the folder
   structure. Every path inside is relative to the folder containing
   project.godot.

   The archive contains 59 files: 40 new, 19 modified.
   Nothing is deleted or renamed.

3. Open the project in Godot once and let it import. The new scripts
   declare class_names (CustomerIdentity, VisitIntentConfig,
   SocialCompatibility and others) which will not resolve until Godot
   has scanned them. Parser errors on the first open are expected to
   disappear after the import completes.

4. project.godot has a NEW AUTOLOAD:

       CustomerBehaviourEvents="*res://systems/customer_ai/identity/customer_behaviour_events.gd"

   If you would rather not overwrite your project.godot, skip that file
   and add the autoload by hand in Project Settings > Autoload. It must
   be present or the customer scripts will fail at runtime.


WHAT TO WIRE IN THE EDITOR
--------------------------
Two things are code-complete but need an Inspector reference, because a
scene file cannot be merged safely:

  - GameManager: set "Visit Intent Registry" to
    res://Data/customer_ai/visit_intent_registry.tres
    Without it customers spawn with no visit intention - they behave
    exactly as they did before, so this fails quietly rather than loudly.

  - Add the three new CustomerTypes to the spawner's "Customer Types"
    array in main.tscn:
      res://resources/CustomerTypes/local_worker.tres
      res://resources/CustomerTypes/merchant.tres
      res://resources/CustomerTypes/pirate.tres
    (sailor, sailor_impatient and captain are already there and have
    been extended in place.)

  - Optional: add systems/customer_ai/ui/customer_behaviour_panel.gd as
    a Node in main.tscn for the F9 developer controls.
