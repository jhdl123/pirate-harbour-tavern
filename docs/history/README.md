# Historical Documentation

Dated change reports, patch notes and one-off cleanup-pass documents. Each
describes what a specific past development pass did — not current state.

None of these have been reconciled against the current repository, and some
describe an earlier stage of the project (for example, before groups, staff
tasks or the beverage framework existed). For current, verified status,
decisions and design, use `CLAUDE.md` and the files directly under `docs/` —
not this folder.

Kept rather than deleted for the reasoning trails some of them contain (bug
traces, tuning history, decisions made and reverted) that the compact current
docs deliberately do not restate.

Note: `CHANGELOG.md` in this folder is itself one such frozen, one-off
report (a single cleanup pass), not a living log. The current, living
changelog is `docs/CHANGELOG.md`, one level up.
