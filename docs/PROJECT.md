# Pirate Harbour Tavern

## Project goal

Learn Godot and game development by building a pirate harbour tavern management game.

## Current milestone

Create a basic playable tavern room with:

- Player movement
- Walls and furniture
- Collision
- One interaction button

## First gameplay loop

Customer enters
→ finds a seat
→ orders grog
→ player serves grog
→ customer pays
→ customer leaves
→ table becomes dirty
→ player cleans table
→ repeat

## Current controls

- WASD or arrow keys: move
- E: interact
- Mouse: menus and user interface

## Development approach

- Desktop-first development
- Godot 4
- GDScript
- Placeholder graphics initially
- One small working feature at a time
- Readable code rather than clever code
